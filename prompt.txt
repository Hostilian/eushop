<project_context>
EUshop is an EU Specialty Food Marketplace Platform.

Tech Stack:
- Backend  : Java Spring Boot (services/core-service), Spring Data JPA, PostgreSQL on port 5433
- Frontend : Next.js (apps/web) under a pnpm workspace
- Database : PostgreSQL — tables: users, foods, orders, reviews, chat, notifications
- Auth     : Auth0 (planned)
- Payments : Stripe (planned)
- Infra    : Docker Compose, GitHub Actions CI/CD

Key Daemon System (CRITICAL CONTEXT):
- This agent is powered by a self-healing, always-on free LLM API key pool
- Keys are harvested hourly from 15+ GitHub repos via GitHub Actions (harvest_keys.yml)
- A local daemon (key_daemon.py) refreshes the pool every hour via git pull + revalidation
- The hot cache lives in .api_keys_pool.json (auto-managed, never edit manually)
- The agent auto-rotates keys and base URLs on failure — the user should never need to intervene
- If asked about key status: suggest running `python scripts/key_daemon.py --status`
- If asked to refresh keys: suggest running `python scripts/key_daemon.py --once`
</project_context>
