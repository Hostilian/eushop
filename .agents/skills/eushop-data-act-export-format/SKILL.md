# EU Data Act (Regulation 2023/2854) — Data Export Format

## Overview
The EU Data Act (Regulation 2023/2854, applicable from 12 September 2025) grants users and business sellers the right to access and share data generated by their use of EUshop. Exported data must be machine-readable, structured, and portable to third-party services without restriction.

// COMPLIANCE-REVIEW: Data Act obligations for B2C platforms are different from IoT/product data obligations. Confirm which provisions apply to EUshop's marketplace model with legal counsel.

## Data Types Subject to Export

| Data Type | Who Can Export | Format |
|-----------|---------------|--------|
| Order history | Buyer, Seller | JSON / CSV |
| Product listings & metadata | Seller | JSON |
| Review & rating data | Buyer | JSON |
| Financial/payout data | Seller | JSON / CSV |
| Search & browsing history | Buyer (GDPR Art. 20 also applies) | JSON |
| DAC7 tax data | Seller | PDF + JSON |
| Compliance documentation | Seller | JSON |

## Machine-Readable Format Requirements

```typescript
// packages/compliance/src/dataAct.ts
export type ExportFormat = 'JSON' | 'CSV' | 'XML';

export function validateExportPackage(
  packageJson: string,
  expectedFormat: ExportFormat
): DataActValidation {
  const errors: string[] = [];
  try {
    const data = JSON.parse(packageJson);
    if (!data.exportId) errors.push('Missing exportId in package root');
    if (!data.dataVersion) errors.push('Missing dataVersion');
    if (!data.exportedAt) errors.push('Missing exportedAt timestamp');
    // COMPLIANCE-REVIEW: "Machine-readable" is not defined as a specific format in the Data Act
    // JSON with documented schema is considered compliant by most interpretations
  } catch {
    errors.push('Export package is not valid JSON');
  }
  return { valid: errors.length === 0, errors };
}
```

## Data Portability (Switching Rights — Art. 23-31)

```typescript
// packages/compliance/src/dataAct.ts
// Art. 23: Users must be able to switch to another data processing service
// within 30 calendar days
export const DATA_ACT_SWITCHING_PERIOD_DAYS = 30;

export interface DataSwitchingRequest {
  userId: string;
  requestedAt: Date;
  targetServiceUrl?: string;  // Where to send the data package
  deadline: Date;             // Must be requestedAt + 30 days
  status: 'PENDING' | 'PROCESSING' | 'COMPLETED' | 'FAILED';
}
```

## Prohibited Contractual Restrictions

The following terms are **non-binding** under Data Act Art. 13:
- Clauses preventing a business seller from accessing their own data
- Clauses requiring exclusive use of EUshop's analytics tools
- Clauses restricting portability of seller transaction data
