# Graphify AST Codebase Analysis Engine

This skill maps codebases into queryable knowledge graphs using deterministic AST parsing.

## Key Capabilities
1. **AST Structural Mapping**: Analyzes dependencies between components, controllers, services, and schemas without re-reading raw files.
2. **Impact Analysis**: Traces ripple effects of function signature modifications across all invocation sites.
