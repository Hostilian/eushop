# EU Geo-Blocking Regulation Compliance

## Non-Discrimination Rules
1. Never block IP addresses originating from any of the 27 EU Member States.
2. Allow cross-border buyers to access any EUshop national interface.
3. Automatically apply correct VAT rate based on buyer destination without blocking access.
