# Organic Certification Verification

## Rules
1. Any product labeled "organic" or "bio" must include the control body code (e.g. FR-BIO-01).
2. Euro-leaf logo must be accompanied by origin statement ("EU Agriculture" / "Non-EU Agriculture").
