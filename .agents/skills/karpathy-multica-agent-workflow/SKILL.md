# Karpathy / Multica Agent Workflow

This skill implements the **multica-ai** and **Andrej Karpathy** software engineering principles for multi-agent AI development.

## Engineering Workflow Guidelines
1. **Agent Team Teammate Model**:
   - Treat AI agents as first-class team members with assigned tasks, status, and deliverables.
2. **First-Principles Problem Solving**:
   - Deeply inspect code and trace failures to root cause contracts rather than applying superficial patches or swallowing errors.
3. **Empirical Verification Required**:
   - Never declare success without running actual build, lint, or test commands.
4. **Clean Code & Non-Bloated Abstractions**:
   - Write simple, explicit, readable code over complex unneeded wrappers.
5. **Session Task State**:
   - Always maintain `task.md` with progress metrics, commit SHAs, and clear remaining action items.
