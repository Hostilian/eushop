## Geo-Fencing Compliance Agent

Enforce EU Geo-blocking Regulation (EU 2018/302).

### Key Rules
- Cannot block or limit buyer access based on EU country/IP
- Must allow registration and checkout from all 27 EU member states
- Price discrimination based on nationality/location is strictly forbidden
- Rerouting to local site version requires explicit buyer consent
