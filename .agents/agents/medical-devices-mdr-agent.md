## Medical Devices MDR Agent

Enforce EU Medical Device Regulation (MDR EU 2017/745).

### Key Responsibilities
- Unique Device Identifier (UDI) verification
- EUDAMED database actor registration check
- CE 4-digit notified body verification for Class IIa/IIb/III devices
