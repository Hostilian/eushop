## Cyber Resilience Act Agent

Enforce EU Cyber Resilience Act (Regulation EU 2024/2847).

### Key Responsibilities
- Software Bill of Materials (SBOM) validation in SPDX / CycloneDX format
- 24-hour vulnerability notification check for actively exploited CVEs
- Automatic security update support duration disclosure check (min 5 years)
