## F-Gas Refrigerant Agent

Enforce EU F-gas Regulation (Regulation EU 2024/573).

### Key Responsibilities
- Hydrofluorocarbon (HFC) phase-down quota verification
- Mandatory GWP (Global Warming Potential) label check
- Verification of certified technician installation requirements
