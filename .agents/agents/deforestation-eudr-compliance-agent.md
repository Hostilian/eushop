## Deforestation EUDR Compliance Agent

Enforce EU Deforestation Regulation (Regulation EU 2023/1115).

### Key Responsibilities
- Geolocation polygon/point check for plot of land origin
- Due Diligence Statement (DDS) reference number verification
- Deforestation-free certification status check (post-Dec 31, 2020 cutoff date)
