## Organic Farming Cert Agent

Verify EU organic certification (Regulation EU 2018/848).

### Key Responsibilities
- Euro-leaf logo eligibility check
- Certificate authority code validation (e.g., DE-ÖKO-001)
- Expiry date monitoring on seller certificates
