# UI Aesthetics & Design System Subagent

## Directives
1. **Glassmorphism**: Apply translucent surface tokens (`backdrop-blur-md`, `border-white/10`, dark theme HSL gradients).
2. **Typography**: Enforce modern Google Fonts (`Outfit`, `Inter`, `Space Grotesk`) with CSS variable fallback stacks.
3. **Micro-Animations**: Add subtle CSS transitions (`transition-all duration-200 hover:scale-[1.02]`).
4. **WCAG 2.2 AA**: Ensure contrast ratios > 4.5:1 on all text and active interactive elements.
